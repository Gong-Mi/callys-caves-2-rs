## Current batch boundary

`reconstruction/contracts/player-combat.json` pins both complete original Alarm
bodies plus every direct spawn target's complete Create body and parent ID. It
is generated by `scripts/package_player_combat.py` from hash-checked recovered
GML, checked against original CODE/OBJT by `test_reverse_player_combat.py`, and
compared with freshly recovered GML in source-recovery CI.

Read-only field access must resolve current state rather than freezing a whole
event snapshot. `instance_create` must execute Create before returning its ID.
The method layer does not promise a working engine merely because a host trait
has all necessary methods. Unit hosts and integration fixtures must be labelled
as synthetic; original-runner differential verification is still outstanding.

Specific contracts not to simplify:

- self fields and `obj_player` selector reads are different operations.
- Weapon flags are independent tests, not one mutually exclusive weapon enum.
- Some facing tests are two independent `if`s, others are `if/else`.
- Non-0/1 mute and facing values retain the source branch behavior.
- Five shotgun bullets each execute their own Create before the next spawn.
- Laser identity is stored in `i1`, re-read, then assigned `image_xscale`.
- Assault-rifle sound uses `audio_is_playing`; most other sounds do not.
- Sword Create retains the existence test and both repeated image-angle writes.
- Spikegun spike has parent object 34; a direct Create is not an instruction to
  automatically run parent Create when no `event_inherited` call exists.
- Random/choose calls and motion builtins need their original evaluation order;
  a mathematical-looking expression is not permission to reorder random draws.

changing that error into success.

### Review correction and regression evidence

Original CODE 11 reads self.y at 0x0039731c, then self.x at 0x0039732c before
instance_create at 0x0039733c. CODE 10 reads obj_player.y at 0x003971a8, then
obj_player.x at 0x003971b8 before instance_create at 0x003971c8; wave creation
also uses Y then X. The first Rust translation read X then Y. A dedicated trace
regression failed with actual [X,Y] versus expected [Y,X], then passed after all
three call helpers were corrected. This is a proven host read-order mismatch,
not evidence that stable initialized coordinates had visibly different results.
Two characterization trace expectations were corrected to this original oracle.

The initial Arrow regression failed against the empty Create function; the full
Create implementation then passed. Other newly added tests are preservation and
integration tests, not a claim that every method was historically test-first.
Local fresh compilation executes the actual Rust methods; local verify_gml checks
the prior hash-pinned source-recovery artifact. Fresh recompilation and strict
GML round-trip are separately performed by Recover original GML CI.
