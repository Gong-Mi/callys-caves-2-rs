# Semantic coverage census (recomputed from evidence)

Generated by `scripts/audit_semantic_coverage.py`. Do not hand-edit. Regenerate after
any contract/test change:

```
python3 scripts/audit_semantic_coverage.py \
    --ledger "$CALLY_CFG_LEDGER" \
    --exec-trace /path/to/CALLY_CODE_TRACE-ledger \   # optional, repeatable
    --md reconstruction/contracts/semantic-coverage.md
```

## Why this exists

`progress.tsv` (the CFG-phase ledger) froze its `stack_semantics` and
`behavior_verified` columns at the phase where they were written; they are not a
progress metric. This census ignores them and derives every row from evidence that
can be re-read at any commit. A citation below means the CODE id (or its object) is
named in that area - it is evidence of ATTENTION, never of runtime equivalence.

Frozen columns observed in the ledger: `stack_semantics` = {'unknown': 1354}, `behavior_verified` = {'no': 1354}.
